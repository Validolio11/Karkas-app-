# Karkas Pulse — перенесення дизайну в застосунок

Макети: `docs/design-pulse/*.dc.html` (лише довідка, не код застосунку). Мова інтерфейсу — українська (англійська через i18n, як зараз).

## Принципи
- Менше екранів: 3 вкладки — **Сьогодні**, **Ріст**, **Блокнот**; Karkas AI — острівець знизу; Налаштування — шестерня.
- Застосунок допомагає діяти, а не показує дашборд. Графік лише на екрані навички.
- Жодних підказок на кнопках: комбінації клавіш — у підказці при наведенні та в Налаштуваннях.
- Токени Pulse: `#090a0a` полотно, `#1f1f1f` плитка, `#3a3a3c` сталь, `#f4f4f2` папір, `#13f287` ріст, `#6408fa` дані/ШІ, `#ff4d4f` відставання. Шрифт Inter (SF Pro Display на macOS). Заголовок 80px ВЕЛИКИМИ (300 + 800). Штрих — частка шляху.
- Сітка: контент 1280, відступи 24/32/120; шапка (заголовок + перемикач, дії праворуч); колонка 400px **ліворуч** + основна колонка.
- Анімації з `prefers-reduced-motion`.
- Дані й синхронізація не ламаються; старі дані мігрують, а не губляться.

## Етапи (після кожного — показ користувачу)
1. **Каркас + «Сьогодні»** — токени, шапка (лого K, 3 вкладки, пошук, шестерня, «+ Додати», аватар, кнопки вікна), острівець ШІ, Ctrl+N / Ctrl+K, підказки при наведенні; екран «Сьогодні»: картка «Зараз», рядок швидкого додавання з розпізнаванням дати/часу/категорії й вибором карток, Практика/Справи, План дня, стани ранок / закриття дня / перший запуск (на основі наявних DayCloseDialog, ранкового підсумку, онбордингу).
2. **«Ріст» (нова механіка)** — модель навички (метрика, напрям, старт/ціль/термін, підскладові, контрольні заміри, сесії практики зі складністю й висновком), статуси На шляху/Випереджаєш/Відстаєш, найслабша ланка; екрани Ріст, Навичка (графік), Тиждень, Нова навичка, Завершення практики. Стратегія (цілі, AI-обговорення) переїжджає сюди: цілі → навички; Історія → «Тиждень» і закриття дня. Синхронізація Firestore для нових сутностей.
3. **«Блокнот»** — редактор: меню виділення (копіювати/вставити/видалити/нумерація/кнопка копіювання), форматування (шрифти Windows, розмір, товщина), сторінки, олівець, закріплення, нові нотатки; міграція `content` без втрат.
4. **Налаштування, вхід і синхронізація, Karkas AI-острівець** — перенесення SettingsModal/AccountModal/AIAssistantSheet у новий вигляд.
5. **Перевірки й випуск** — лише після окремого дозволу користувача.
