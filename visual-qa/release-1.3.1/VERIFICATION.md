# Karkas 1.3.1 — перевірка перед випуском

Користувач погодив випуск після локальної реалізації без тестів. Перевірки виконано перед публікацією; знайдені проблеми виправлено, змінені сценарії перевірено повторно.

- Повний набір: **467/467 тестів**, без пропусків і помилок.
- TypeScript: успішно.
- Production: успішно; фінальний renderer `app-hrG-eDiD.js`. Усі 12 джерел серверної source map відповідають фінальному коду.
- Інтерфейс: шість груп сценаріїв на 1440×1000 та 375×812, без необроблених помилок React і горизонтального переповнення. [Докази й межі UI-перевірки](QA-REPORT.md), [машинний результат](qa-results.json).
- Знайомство: список бажань, адаптивні питання, кілька тем, заперечення, «не знаю», приватні відмови, конкретний підсумок і випадкове «так».
- Пам’ять: перерване знайомство, старий профіль, довга розмова, виправлення джерела, повтори та ізоляція гостя/акаунтів. Історія й чернетки мігруються до окремих ключів без змішування з акаунтом `guest`.
- Звичайні команди, таймери, підзавдання й аналіз доступні під час знайомства. Неприпустимі пропозиції та помилки формату не обходять перевірку дій.
- Автономне редагування використовує точний знімок на момент запиту: зберігає виміряні й завершені кроки, час та прогрес. Undo, новіші ручні правки, пізня скасована відповідь і `@analysis` перевірені окремо.
- Windows packaged runtime: **2/2 успішні**. Запущено лише режим Node перевіреного пакета; інсталятор і встановлений застосунок користувача не запускалися.

Справжні платні ШІ-запити та входи двох живих Firebase-акаунтів не виконувалися. Для SDK використано контрольовані HTTP-відповіді; для UI — синтетичні профілі й окремі браузерні контексти. Синхронізація та офлайн перевірені наявними модульними сценаріями. Поточний preview 54736 збережено й перезапущено з новим серверним кодом без підміни даних.
