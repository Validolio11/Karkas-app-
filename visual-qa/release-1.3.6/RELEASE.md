# Karkas 1.3.6 — випуск для ручної перевірки

- Користувач попросив випустити локальні виправлення, щоб перевірити їх самостійно. Автоматичні тести, TypeScript і запуск інсталятора не виконувалися.
- Незалежний огляд коду не виявив очевидних блокувальних помилок. Причину конкретного попереднього збою Google не підтверджено; нові коди розділяють недоступність провайдера та внутрішні помилки додатка.
- Production і Windows x64 NSIS зібрані успішно; попередження про великий вебпакет залишається.
- Версія Windows-файлу 1.3.6, інсталятор 139115324 байт. Назва, розмір і SHA-512 збігаються з latest.yml; blockmap 146523 байт.
- Інсталятор, blockmap і latest.yml завантажені в чернетку. Перед публікацією перевірено розміри та надані GitHub SHA-256.
- Опубліковано https://github.com/Validolio11/Karkas-app-/releases/tag/1.3.6 ; GitHub latest вказує на 1.3.6.
- Використано тег 1.3.6 без префікса v, щоб не запускати workflow з автоматичними тестами.
- Користувацькі дані й сторонні артефакти не змінювалися.
