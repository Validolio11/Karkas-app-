# Локальні виправлення аудиту — 12 жовтня 2026

Початкова база — Karkas 1.3.2 (`45eaea9`), перелік проблем — `CODE-AUDIT-2026-10-12.md`. Версію не підвищено; публікацію не виконано.

## Внесені зміни

| Пункт аудиту | Реалізація |
| --- | --- |
| 1. Втрата кроків/часу | Патчі кроків за ID; журнал сесій із максимумом виміряного часу для спільної сесії; незалежні сесії підсумовуються. Повтори mutation захищені чинним watermark. Скидання й ручна корекція створюють часову епоху; старі часові зміни та запуск таймера відкидаються. |
| 2. Некоректні сутності | Спільний runtime-парсер cloud/renderer/native. Початкове локальне сховище, account cache, base й metadata перевіряються перед застосуванням. Некоректне джерело зберігається для відновлення; без успішної резервної копії перезаписування блокується. |
| 3. Завдання без категорії | Після merge посилання узгоджуються; завдання з відсутньою категорією зберігаються у «Відновлених завданнях». |
| 4. Спільні нотатки | Окремі сховища нотаток, чернеток і пам’яті сеансу для акаунтів та гостя. Старі дані мігрують лише початковому власнику, початкові значення збережено. Застарілі callback нотаток блокуються за owner/epoch. |
| 5. Скасування Google-входу | Redirect fallback лише для заблокованого popup; закриття/скасування не запускає повторний вхід. |
| 6. Кеш стратегії | Спільний парсер відповіді API та кешу перевіряє поля й кожну рекомендацію до рендерингу. |
| 7. Хибна ціль команди | Невідома конкретна назва більше не підставляє єдине інше завдання. Підстановка дозволена лише для обмежених однозначних неназваних команд. |
| 8. Ліміт автономних змін | Одна константа: максимум три дії; перевищення відхиляється сервером і клієнтом. |
| 9. Транскрипція | Спільний bounded transport, abort попередньої спроби й очищення таймерів; пов’язане скасування клієнта передається до провайдера. |
| 10. Календарні межі | Фактичні межі дат включено в контекст кешу; локальні показники оновлюються на межі доби та при поверненні у вікно. Генерація не запускається автоматично. |
| 11. Перезаписування форми | Форма передає очікуваний початковий текст; записує лише змінені поля й відхиляє конфлікт. Незбережена чернетка залишається у формі. |
| 12. Вкладені діалоги | Підтвердження видалення володіє фокусом та Escape; нижній focus trap призупинено, додано семантику діалогу. |
| 13. Інсталятор | Native незалежно отримує дозволений офіційний реліз, перевіряє HTTPS/redirect, точні URL/назву, розмір та SHA-512 із latest.yml. Хеш перевіряється повторно перед запуском; недовірений пакет блокується. |

Об’єднано canonical-серіалізацію, фабрику GoogleGenAI та форматування тривалості. Історія локалізує одиниці часу. Логіку нотаток винесено з App в окремий hook; перевірку оновлень і локальних даних — в окремі модулі.

## Статус перевірок і межі

Зміни перечитано статично, частини переглянуто незалежним субагентом. Тести, TypeScript-перевірку, production/Windows-збірки, живі AI-запити й випуск не запускали. Реалізація ще не підтверджена виконанням.

Додано окремі `typecheck` та `typecheck:strict` і конфігурацію `tsconfig.quality.json` зі строгими правилами. Строгий профіль підготовлений для наступного дозволеного проходу; його успішність не встановлена, глобальний режим наосліп не перемикали. Повний поділ великих компонентів на модулі не завершено: виконано пов’язане з цими виправленнями винесення логіки.

Журнал сесій навмисно зберігає історичні ID, щоб старий офлайн-пристрій не зарахував час повторно. Безпечна компактизація потребує узгоджених watermark усіх пристроїв; захист максимального cloud payload залишається чинним.

Якщо резервування пошкоджених локальних даних неможливе, збереження блокується з поясненням. Після звільнення місця потрібно перезапустити застосунок для повторного відновлення. Некоректний cloud workspace не замінюється порожніми даними.

Після окремого дозволу потрібні регресії двох офлайн-пристроїв, спільної/незалежних сесій, повторів sync, скидань і корекцій, старих профілів/кешів, перемикання акаунтів, конфліктів форми, клавіатури, скасування транскрипції та недовіреного інсталятора. Потім перевірка типів і збірок перед випуском.
