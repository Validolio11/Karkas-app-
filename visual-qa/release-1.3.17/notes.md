# Karkas 1.3.17

- «Сплануй мені день…» — Karkas AI розкладає справи по годинах («14:00–15:00 → 15:00–15:30 → …»). Години рахує сам додаток, блоки не накладаються.
- Час можна називати звичайними словами («з пів першої до третьої», «пів другої»). Якщо тривалість не сказано, ШІ оцінює її сам і позначає «орієнтовно».
- Наявні завдання переплануються без дублів, таймери на потрібну тривалість ставляться на паузу.
- Завдання отримують вкладку за змістом і пріоритет: P1 для головного, P3 для відпочинку.
- На картці видно «Сьогодні 14:00–15:00», а сьогоднішні заплановані справи стоять угорі списку в порядку годин. Увесь план можна скасувати однією кнопкою.

Перевірено на справжньому Gemini: план дня з оцінками й названими годинами, вкладки, пріоритети, оновлення наявного завдання, «Скасувати» та вузький екран.

Windows x64: **Karkas-Setup-1.3.17.exe**.
