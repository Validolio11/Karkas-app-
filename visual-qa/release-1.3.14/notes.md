# Karkas 1.3.14

- ШІ враховує уточнене в розмові завдання при повторних командах таймера.
- Додано пропозиції корекції вже відпрацьованого часу: «забув запустити таймер, зарахуй 3 години». Показується загальний час роботи; запис відбувається після підтвердження.
- Стан таймера та залишок відліку зберігаються. Застарілі пропозиції після ручних змін блокуються.
- Уточнення, скасування та повтор запиту зберігають узгоджену чернетку пропозиції.
- Виправлено запуск таймера після явного повторного відкриття завершеного завдання.

Перевірено завдання, підзавдання, таймери, історію, кошик, вкладки, статистику, нотатки та AI-пропозиції. Інтерфейс перевірено на звичайному й вузькому екранах. Тести AI використовували підставні відповіді моделей.

Windows x64: **Karkas-Setup-1.3.14.exe**.
