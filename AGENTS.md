# Правила роботи над Karkas

- Використовуй субагентів для роботи над проєктом; доручай їм конкретні завдання без дублювання роботи.
- Тести й випуск оновлення виконувати лише після окремого явного дозволу користувача. До такого дозволу робити тільки погоджені зміни; попередній дозвіл на завершений випуск не переноситься на нові зміни.
- Спочатку реалізуй узгоджений набір змін і виправлень. Запускай тести перед випуском оновлення, а не після кожної проміжної правки, щоб економити ліміти чату.
- Перед випуском виконай потрібні перевірки, виправ знайдені проблеми й повторно перевір змінені сценарії. Випускай оновлення після успішних перевірок.
- Не повторюй успішні перевірки без нових змін, помилок або невирішених питань.
